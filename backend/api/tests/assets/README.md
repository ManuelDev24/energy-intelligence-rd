# Synthetic OCR test fonts

These unmodified font binaries are from the official DejaVu Fonts 2.37 release, tag `version_2_37`:
https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37

They make generated invoice fixtures reproducible across Linux and macOS; they are test data, not production UI assets. License and attribution are in `LICENSE`.
